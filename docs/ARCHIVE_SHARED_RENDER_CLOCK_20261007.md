# 기록 재생의 공통 렌더 시각

카메라 품질·텔레메트리 알림이 재생 틱 사이에 화면을 다시 그릴 때도 현재 영상의
시각을 한 번 읽고 LiDAR·IMU·GPS·PWM·지도에 동일한 커서를 전달한다.
기존 원본 수신시각과 영상 offset은 그대로 사용한다.

일시정지·seek·지도 버퍼링·영상 소스 전환 중에는 사용자가 선택한 커서를 유지한다.
늦게 완료된 Play 또는 지도 재개 요청은 Stop을 취소하거나 새 Play를 정지시키지 않는다.
영상 소스의 metadata 알림이 커서 복구 전에 임시로0초 화면을 표시하지 않도록 한다.

원래 관측한497ms의 상태 지연 사례를 포함한 실제 app 함수10검사와 기존 영상/지도
시각 회귀2검사, JavaScript 문법 검사를 통과했다. 이는 mock 기반 검사이며 실제
브라우저·느린 회선 검증과 SSH 적용 결과는 별도 체크포인트로 남긴다.
기록 원본과 지도 자료는 변경하지 않는다.
