# 과수원 기록 지도 형상 진단 · 2026-10-04

사용자가 지적한 대상은 저장된 과수원 기록의 재생 지도다. 실제 대시보드의 live/archive 차량 화살표만 180도 돌렸다. 원시 LaserScan·IMU·추정 pose·이동경로·점유 셀 좌표는 변경하지 않았다. SIM 차체 좌표계의 화살표는 기본 회전값 0을 유지한다.

기존 raster는 450개 이하로 빈 공간의 광선을 샘플링하면서 물체의 반사점도 함께 버렸다. 과수원 080351/080909의 각 100개 균등 선택 원시 스캔에서 관측된 endpoint 셀 83,281/92,523개 중 기존 방식은 44.4%/40.4%만 occupied로 남겼다. 새 방식은 실제 finite hit endpoint 전체를 셀에 넣고 교차하는 free ray보다 우선한다. 같은 셀을 한 scan에서 여러 번 가중하지 않는다. 빈 공간 ray 계산량은 종전처럼 제한한다. 이 검사는 점 유실 수정의 근거이며 전체 지형 정확도 검증은 아니다.

원시 센서 SHA만 확인하던 trajectory 캐시에 localization 코드 지문을 추가했다. raster 코드 지문도 history에 기록한다. 이전 방식의 지도는 표시를 유지하며 재생성이 필요한 상태로 구분한다. 재생성 전 trajectory/history pointer를 별도 파일로 보존하고, 재생성 실패 시 기존 history pointer를 정확히 복구한다. 원본 bag·sensor extract·GPS·PWM·metadata는 수정하지 않는다.

위치 추정 문제는 별도로 남아 있다. 기존 080909의 2,093개 scan 중 1,816개를 수락하고 23개 local 구간으로 나누었다. 거부 구간을 정지로 간주하거나 PWM/GPS만으로 연결하지 않는다. 080351도 48개 구간으로 나뉘어 있어 현재 결과를 과수원 전체의 연속적인 정확한 지도라고 부를 수 없다.

native gravity 축 gyro와 LiDAR 상대 회전의 비교에서 유효 sweep-end 시각으로 IMU를 대응하면 상관계수가 약 0.85에서 0.96으로 좋아졌다. 이는 기록상의 시각 대응 진단이다. 물리적인 시간 보정이나 beam deskew를 완료했다는 뜻은 아니다. S2 SDK의 각도 보상/배열 정렬과 실제 회전 순서를 확인하지 않고 배열 index를 시간 순서로 사용하지 않았다.

signed gyro·keyframe·최근 submap 후보와 비인접 scan 제약을 사용하는 offline pose graph를 시험했다. 일부 후보는 구간 수를 줄이거나 도로의 중앙 residual을 낮췄지만 두 과수원에서 일관되게 geometry residual을 개선하지 못했다. 최신 submap 후보의 080351 동일 비교쌍 median은 기존 0.10642m, 후보 0.10672m였다. pose graph 후보의 080909 10초 간격 비교는 기존 0.37890m, 후보 0.38837m였다. 개선되지 않은 후보를 실제 mapper에 설치하지 않았다. 이 residual은 sensor geometry 일치도이며 독립적인 지형 정답과의 절대 오차가 아니다.

장착 기울기·진동으로 같은 2D scan plane이 지면/가지의 다른 높이를 관측하는 문제, 미측정 LiDAR–차체/IMU 회전 및 GPS lever arm, 장기간 drift와 단절을 처리하는 관측 가능성 검증은 계속 필요하다. 카메라와 PWM은 이번 측위 입력에 넣지 않았다. 실차 자율 모터 출력은 보류 상태다.

코드 단위 검증은 좁은 물체 반사점 보존, sampling 밀도와 무관한 hit confidence, 코드 변경 시 캐시 무효화, 실패한 재생성의 이전 지도 복원, 재생 시각/뒤로 탐색/zoom/화살표 Canvas 검사를 포함한다. 배포·실제 기록 재생성의 관측 결과는 후속 체크포인트에 기록한다. 원시 좌표·영상·궤적·실험 후보는 private audit에 보관한다.
