# 센서 WebSocket 개선판 설치 확인 — 2026-10-24

이 작업 브랜치의 제품 커밋 `fef9bfd67fc74bd615cdb158f283d5a90faca4e2`에서 `dashboard_server/app.py`와 `dashboard_server/ws_relay.py`만 기존 Jetson 이미지 위에 적용했다. 설치는 2026-10-24 14:21 KST에 완료됐고, 별도 읽기 전용 조회에서도 healthy·조종 해제·정지·녹화 idle·매핑 idle을 확인했다. 모터 출력을 보내지 않았다.

수정은 느린 WebSocket 수신자가 미리보기 relay 스레드를 무기한 막는 문제와 서버 생성 실패 시 정리 필드가 준비되지 않았던 문제를 해결한다. 양방향 버퍼는 각각 64KiB로 제한하고 부분 전송을 처리하며 역방향 ACK가 계속 진행되도록 한다. 한 방향에서 8초 동안 전송 진전이 없으면 연결을 끝낸다. TCP 조각 사이에 임의 상태 프레임을 넣지 않는다. 카메라 데이터의 화질·해상도·기록 설정을 바꾸지 않는다.

설치 전 별도 ARM 검사 이미지에서 순수·실제 소켓·실제 관찰 작업자 정리 시험을 포함한 24개가 skip 없이 통과했다. 생성 영상 기반 Linux 인증·카메라 시험 2개, 실제 관찰 작업자와 bind 실패 정리 시험 2개 및 loopback 시험 2개도 별도 범위에서 통과했다. 생성 영상의 약 29fps는 현장 원본 촬영률을 증명하지 않는다.

기존 UI, 수동 조종·STOP API 및 archive backend는 그대로다. 설치자는 Docker API와 원 컨테이너 inspect를 사용했고 compose는 사용하지 않았다. runtime 설정 일치, 나머지 14개 서비스 동일성, 내부 파일 SHA와 Python 구문을 확인했다. 이전 컨테이너는 자동 재시작을 끈 정지 상태로 남겨 복구할 수 있다.

이 결과는 위 두 파일의 설치 및 해당 기능 시험에 한정된다. 느린 인터넷의 모든 환경, 장시간 다중 클라이언트 성능, 지도 정확도, 자율주행이나 물리 제동을 검증한 결과가 아니다. 설치 전 시험에서 발생한 이전 버전의 lifecycle 실패는 삭제하지 않고 별도로 보존했다.
