# GPS 화면 갱신 · 2026-10-07

같은 GPS 위치·정확도·표시 경로를 MapLibre에 반복 전송하지 않는다.
화면별 예약 작업은 하나이며 최신 선택 표본을 그린다. 재생·정지·되감기·
드래그·사용자 확대와 원시 수신 시각은 유지한다. 경로 중간의 좌표·유효성·
끊김 보정도 실제 표시 좌표를 비교해 반영하며 정렬된 입력을 가정하지 않는다.
신규 행동 검사21개와 기존 GPS 모델·제스처·수신 검사를 사용한다.

실제 Cloudflare 기록의 CPU profile에서는 최초 GPS WebGL shader compile/link가
약0.9–1.2초 메인 스레드를 막았다. 이 변경은 불필요한 갱신을 줄이며
최초 shader 지연을 제거하거나 지속 재생 성능을 합격시킨 근거는 아니다.
경로 생성·비교의 선형 비용은 남고 vendor·WebGL 설정은 변경하지 않는다.
