# Raw sensor checks

- Camera source dimensions, frame id, observed FPS and receipt age.
- LiDAR valid range points, scan frame and receipt age.
- IMU quaternion, acceleration m/s2, angular velocity rad/s and calibration state.
- GPS valid fix only; no fabricated position or RTK.
- Manual controller ownership, input expiry and STOP state.
- No AI confidence, fusion weight or tree detection score is produced.
