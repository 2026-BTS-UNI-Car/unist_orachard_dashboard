# 검증된 화면 오류 수정 — 2026-10-24

사용자의 즉시 반영 지시에 따라 실제 설치본 b782d9b를 기준으로 화면 수정만 분리했다. ui-perf 브랜치 전체와 서버 성능 후보를 가져오지 않았다. Jetson에서 실제 static 42개(3.64MB)를 읽기 전용으로 보존했고, 로컬 기준과의 차이가 줄바꿈뿐임을 확인했다.

수정은 카메라 설정 실패 시 선택값 복원·중복 요청 차단·늦은 상태 응답 무시, LiDAR 화면 오류 시 ACK 유지, 기록 목록 갱신 시 재생 위치·미디어 유지, 같은 기록 재선택 시 지도 epoch 유지, 구형 브라우저 요청 취소·시간초과와 HTML 오류 응답 처리, GPS 자동 전송 프로필 선택, 저장소 접근 실패 시 전체 센서 보기 유지다. 차트 시간축 표기도 현재 갱신 주기와 맞춘다.

런타임 변경 대상은 `static/app.js`, `static/field-preparation.js`, `static/gps-map.js`, `static/live-map.js` 네 파일뿐이다. 서버·제어 코어·STOP 타이밍·모터·펌웨어·센서 보정·지도 알고리즘은 변경하지 않는다. 별도 성능 브랜치의 늦은 live poll 차단(S17) 전체가 포함됐다고 보고하지 않는다.

로컬 구문 검사 네 개와 집중 기능 시험 다섯 개를 통과했다. 제품 함수를 실행해 같은 기록 갱신·이전 응답 무시·카메라 선택 복구·오류·지도 취소·기존 현장 준비 화면을 확인했다. 실제 Chrome 단회 LAN에서 STOP/Esc/탭 hidden+blur/키 해제/옛 lease 거부의 10단계를 인증된 파일 전용 FakeMotor로 통과했다. 이는 실차 제동·느린 회선·전체 기록 재생·지도 정확도·종합 성능 개선의 검증이 아니다.

설치는 실제 부모 이미지 위에 네 파일만 올리는 overlay를 사용한다. 이전 컨테이너와 inspect·파일은 보존하고 Docker API로 기존 설정을 이어받는다. 설치 전후 건강 상태·무조종·녹화 idle·파일 SHA·다른 서비스 불변을 확인한다. 설치 여부와 롤백 위치는 실제 결과가 생성된 후 별도 운영 기록에 남긴다. compose로 대시보드를 재생성하지 않는다.
