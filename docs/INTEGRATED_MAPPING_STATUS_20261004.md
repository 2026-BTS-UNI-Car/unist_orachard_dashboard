# 통합 지도 및 좌표 전송 적용 체크포인트 · 2026-10-04

실제 Jetson 실시간 지도와 10월 3일 기록 7개는 raw LiDAR·IMU 정합 및 품질 가중 GNSS 위치 제약을 사용하는 공통 engine에 연결했다. 점유 지도는 PNG 대신 좌표·해상도·숫자 셀 상태를 전송하고 웹 Canvas가 그린다. 처음은 전체 타일, 이후는 변경된 블록을 대체한다. 기록 재생은 센서 시각별 이벤트와 선행 캐시를 사용하며 뒤로 탐색할 때 미래 셀을 보여주지 않는다. 원본 자료와 log-odds checkpoint는 보존한다.

원본 32,047개 스캔 중 승인된 30,742개를 98개 분리 submap으로 저장했다. 이 숫자는 과수원 전체가 하나의 정확한 지도라는 의미가 아니다. 정합 실패·관측 부족으로 위치를 모르는 구간을 GPS나 PWM으로 억지로 이어 붙이지 않았다. 장착 기울기·GPS 안테나 offset·rolling-ray 시간·독립 위치 기준은 아직 검증되지 않았다. 카메라와 PWM은 측위 입력으로 사용하지 않는다.

실차 모터를 구동하지 않은 약 6초 정지 시험에서 61개 스캔을 반영했고 source queue drop 0, 마지막 receipt-to-map 지연 약 46ms를 관측했다. STOP 뒤 지도 셀은 유지됐다. 이는 정지 환경의 source-rate 처리 검증이며 주행 중 절대 위치 정확도나 모든 노면에서의 처리 속도를 보증하지 않는다.

같은 숫자 셀 형식과 공통 Canvas renderer를 로컬 SIM 실시간 지도에 적용했다. SIM의 기존 wheel·IMU pose 공급은 이번 표시 변경으로 교체되지 않았다. sensor-only 공통 engine으로의 SIM 전환과 기존 SIM 기록의 시각별 재생은 다음 작업이다. 기존 PNG 전용 기록은 호환 표시를 유지한다.

새 녹화에는 원본 해상도 JPEG topic과 raw-rate mapping sensor sidecar, 녹화 종료 후 VFR/HLS 준비 경로를 설치했다. 과거 기록의 1080p raw Image는 약 1.14~1.69FPS로 성기게 기록됐고, 기존 720p 영상은 약 13~15FPS다. 둘을 같은 프레임 속도의 화질 단계로 취급하지 않는다. 별도 1080p 원본 선택 UI/변환 도구는 구현했지만 7개 기존 기록의 1080p 영상 변환·설치는 아직 남아 있다. 새 실제 녹화의 capture·encode·bag FPS 부하 검증도 필요하다.

야간 072238/073551은 사용자의 야간 확인과 GNSS UTC/host receipt 차이를 근거로 표시시각 sidecar를 설치했다. 원본 ID·metadata·bag와 센서 상대시각은 변경하지 않았다. 기록 정렬은 폴더 수정시각 대신 표시시각/ID를 사용한다. raw GPS UTC 품질 플래그가 기록되지 않았던 자료이므로 보정은 추정으로 표시한다.

실제 자율 모터 출력은 보류한다. 추가 PWM 모델 식별·제동·좌우 편향, 물리 보정/독립 주행 지도 평가, SIM sensor-only 전환, 새로운 과수원/가지/벽/마지막 열 검증, 긴 느린 회선 재생 시험은 미완료다. API/화면 동작이나 보기 좋은 점유 격자만으로 자율주행 합격을 선언하지 않는다.

배포 이미지·검증 집계는 `cell_mapping_deployment_20261004.json`, 전송 규격은 대시보드의 `GRID_CELL_TRANSPORT.md`를 참조한다. 직접 SSH 배포했으며 GitHub Actions는 사용하지 않았다. 원본/좌표/영상/궤적 artifact는 private audit 폴더에만 보관한다.
