# 복도 주행 시험 준비와 당일 순서

작성 2026-11-17. 건물 복도에서 처음으로 조향 장치를 단 차를 땅에 놓고 굴려, 자율주행(MOTOR)을 켜기 전에 비어 있는 값을 잰다.
복도의 길이·폭은 모른다. 시작할 때 LiDAR로 재고 움직일 거리를 그에 맞춘다.

## 1. 이 시험으로 채우는 값

실행기 안전 검사는 아래 값이 비어 있으면 차를 움직이는 모드(MOTOR)를 거절한다. 지금 들어 있는 값과 출처를 함께 적는다.

| 값 | 뜻 | 지금 | 이 시험에서 |
| --- | --- | --- | --- |
| B0 조향 극성 | 왼쪽 명령에 바퀴가 왼쪽으로 도는가, 조향 드라이버 차단이 되는가 | 확인 안 됨(가운데 맞출 때 눈으로 본 증거만) | 바퀴 띄운 채 확인 |
| B4 조향 시작 PWM | 조향 모터가 움직이기 시작하는 PWM | 비어 있음 | 바퀴 띄운 채, 땅 위에서 한 번씩 |
| B2/B3 조향 범위 | 명령 ±20일 때 바퀴의 실제 각도 | 18.9° 추정('끝이 20°'라는 가정) | 휴대폰 각도 앱으로 재기 |
| F1 영점 오차 | 조향 0으로 직진할 때 휘는 정도 | 0° 추정(눈으로 맞춘 가운데, ±0.4°) | 5~10 m 직진, 양쪽 벽 거리 변화 |
| C2 출발 duty | 차가 움직이기 시작하는 구동 duty | 34 %(10월, 조향 장착 전 차) | duty를 조금씩 올리며 |
| C3 주행 속도 | 기본 duty 55 %에서의 속도 | 0.459 m/s(10월 과수원, 참고 등급) | duty 40 / 55 / 70 %에서 LiDAR로 |
| C7 정지 거리 | 달리다 구동 0으로 멈출 때 미끄러지는 거리 | 0.595 m(10월, 약 0.9 m/s에서 키를 놓음) | 실행기 속도에서 직접 |
| 땅 조향 속도 | 무게가 실린 상태의 조향 속도 | 13.1 °/s(바퀴 든 상태) | 정지 상태 ±10°, ±20° |
| 거리 명령 보정 | 대시보드 "1 m 앞으로"의 실제 거리 | 없음 | 1 m 명령 3번, 줄자 |
| 구동 감시 | 명령이 0.3 s 끊기면 구동이 멈추는가 | 펌웨어에 넣었지만 보드에서 재지 않음 | 바퀴 띄운 채 확인 |

## 2. 전날 준비 (사용자)

- [ ] 배터리 완전 충전(구동·조향 모터용). 충전 상태를 적어 둔다.
- [ ] 차체를 띄울 받침대(바퀴가 바닥에 닿지 않게).
- [ ] 물리 비상정지가 작동하는지 확인.
- [ ] 줄자(5 m 이상), 마스킹 테이프(출발선과 표시), 휴대폰 각도 앱(바퀴 각도용).
- [ ] 노트북 또는 휴대폰에서 bts.sarihub.com 대시보드 열리는지.
- [ ] 복도: 사람이 없는 시간, 바닥 종류(타일·장판·콘크리트) 메모, 길이 10 m 이상이면 좋음.
- [ ] 시험 날짜를 알려 주면 시험 도구와 순서를 미리 맞춰 둔다(나).

## 3. 당일 시작 전 (함께, 10분)

- [ ] 젯슨 전원 켜기. 접속이 안 되면 Cloudflare 로그인을 한 번 해 준다.
- [ ] 내가 확인: 대시보드, ESP32-S3 브리지(연결·펌웨어·보정 1475/2017/2513·SMOOTH), 실행기(SHADOW), LiDAR·IMU, 기록기.
- [ ] 사용자가 말로 허락: "오늘 시험은 너가 구동해도 돼". 작업 지침의 '원격으로 구동하지 않는다' 규칙의 이날 예외다.
- [ ] 내가 시험 동안 구동 상한을 낮춘다(예: 40 %). 끝나면 153으로 되돌린다.
- [ ] 역할: 사용자는 차 옆에서 비상정지와 대시보드 STOP, 나는 정해진 짧은 움직임만 하나씩 보낸다. 매번 무엇을 할지 먼저 말하고 "준비됐다"를 듣고 보낸다.

## 4. 차체를 띄운 채 (15분)

1. [ ] **B0 조향 극성:** 왼쪽 5° → 사용자가 "바퀴가 왼쪽" 확인, 오른쪽 5° → "오른쪽" 확인. STOP 뒤 조향 드라이버가 꺼지는지 확인.
2. [ ] **B4 조향 시작 PWM:** 조향 PWM을 조금씩 올려 움직이기 시작하는 값을 잰다(양쪽).
3. [ ] **B2/B3 조향 범위:** 명령 0 / −20(왼쪽 끝) / +20(오른쪽 끝)에서 사용자가 각도 앱으로 앞바퀴 각도를 읽어 준다. 양쪽 바퀴를 따로 잴 수 있으면 둘 다.
4. [ ] **구동 방향:** 구동 duty 25 %로 0.5초. 두 바퀴가 앞으로 도는지 사용자가 확인(W가 앞).
5. [ ] **구동 감시:** 구동 중 명령을 끊으면 0.3초 안에 멈추는지(기록으로 확인).

## 5. 땅 위 (30~40분, 차 옆에 사람)

시작할 때 LiDAR로 앞 벽까지 거리와 복도 폭을 잰다. 앞 벽이 정해진 거리(예: 1.5 m)보다 가까우면 시험 도구가 출발하지 않는다.

1. [ ] **C2 출발 duty:** duty를 20 %부터 2 %씩 올려 차가 움직이기 시작하는 값. 3번.
2. [ ] **C3 주행 속도:** duty 40 / 55 / 70 %로 각 2~3 m. LiDAR 앞 벽 거리로 속도를 잰다. 각 2번.
3. [ ] **C7 정지 거리:** duty 55 %로 달리다 구동 0. 미끄러진 거리를 LiDAR와 줄자로. 3번.
4. [ ] **F1 직진 휨:** 조향 0, duty 40 %로 5~10 m 직진. 양쪽 벽까지 거리 변화로 휜 정도를 잰다. 2번(왕복 방향 바꿔).
5. [ ] **땅 조향:** 정지 상태에서 0 → ±10 → ±20 → 0. 조향 시간과 끝까지 가는지 본다. 그다음 duty 40 %로 천천히 가면서 ±5°.
6. [ ] **거리 명령 보정:** 대시보드 거리 명령 "1 m 앞으로"를 3번. 줄자로 잰 실제 거리를 화면에 넣는다.
7. [ ] (선택) **SHADOW 확인:** 사용자가 W로 천천히 복도 가운데를 직진하는 동안, 실행기가 복도 중심선을 바르게 잡는지 기록으로 본다(차를 움직이는 건 사람).
8. [ ] (선택) **저속 MOTOR 1번:** 위 값이 모두 채워져 실행기 안전 검사를 통과할 때만. 0.2 m/s, 3~5 m, 사용자 옆, 비상정지. 복도는 과수원 열과 달라서 열 끝 판정은 시험하지 못한다(끝 벽에서는 장애물로 선다).

## 6. 끝나고

- [ ] 내가 구동 상한을 153으로 되돌리고 STOP·Arm 해제를 확인한다.
- [ ] 기록(LiDAR·IMU·조향·구동, 시험 도구 기록)을 PC로 옮겨 C2·C3·C7·F1·B2/B3·B4·땅 조향 속도를 계산한다.
- [ ] 새 현장 기록 파일로 실행기 차량 설정에 넣고(옛 기록 보존), 시험·확인을 거쳐 실행기를 다시 설치한다.
- [ ] 결과를 todo 체크포인트와 노션 06 쪽에 적는다. 복도 바닥 값은 '실내 평지'로 두고 과수원 값과 섞지 않는다.

## 7. 안전 규칙 (당일)

- 사람이 차 옆에 있고 물리 비상정지를 바로 누를 수 있을 때만 움직인다.
- 한 번 움직임은 짧게(1~2 m, 시간 상한), 시험 동안 구동 상한을 낮춘다.
- 앞 벽이나 장애물이 가까우면 시험 도구가 출발하지 않고, 가는 중이면 선다.
- 젯슨 연결이 끊기면 브리지(0.75 s)와 펌웨어 구동 감시(0.3 s)가 구동을 멈춘다.
- 이상한 소리, 냄새, 조향이 끝에서 밀리는 느낌이 있으면 바로 멈추고 기록한다.

## 8. 아직 모르는 것

- 복도 바닥과 과수원 흙의 차이: 복도 값은 과수원 값을 대신하지 않는다.
- 모터 전류가 흐를 때 가변저항 값이 흔들리는 원인(11/16 밤). 지금 펌웨어(r5)는 피해 가지만 땅에서 무게가 실렸을 때는 처음 본다.
- 조향 유격(같은 가운데를 오른쪽에서 오면 조금 오른쪽으로 보임).
