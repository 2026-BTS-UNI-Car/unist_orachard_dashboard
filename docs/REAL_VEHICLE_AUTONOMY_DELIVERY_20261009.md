- 저속 전진 PWM preview를 구현하고 16개 순수 검사를 통과했다. 시험 fixture의 값은 실차 측정값이 아니다. ESP 송신이나 모터 권한은 없다.
- LiDAR 두 위치의 SE(2) 변위에서 장착 회전·레버암을 고려하는 차체 속도 관찰기를 구현했다. 원본 시각·프레임·인과적 IMU·연속성·신선도 검사와 중단 시 무효화가 포함된다. 측정된 장착값과 검증 선언이 부족하면 BODY는 HOLD/null이다.
- 현재 실시간 지도에 위치 피드백 진단 연결을 준비했다. 정합 성공한 두 원본 scan만 사용하고 거부·위치 복구·GPS prior·중단·재연결 구간을 새 속도 측정으로 사용하지 않는다. 지도 생성 오류와 진단 오류를 분리한다.
- 기존 WEB WebSocket에는 DDS CDR/GID·원본 RAW callback 시계·발행자 세션 근거가 없다. 해당 경로의 값은 **LiDAR 좌표계 진단값**이며 차체 속도나 실차 제어 승인으로 승격하지 않는다. 기존 지도 알고리즘과 raster는 유지한다.
- 순수 회귀 56개를 통과했다. 10월 3일 7개 기록의 각 첫 40스캔에서도 기존 pose/지도 셀과 일치했고 Stop 후 지도를 보존했다. 이 검사는 합성 receipt를 사용하는 원본 기록 prefix 검사이며 지형 정확도·GPS 융합·실시간 성능·물리 주행 합격이 아니다.
- 지속 native owner를 위한 독립 lifecycle 부품을 준비했다. 한 작업자만 유지하고 중단 시 늦은 결과를 차단하며, 진단 자료를 유한 ring에 보관한다. timeout이나 정리 결과가 불확실하면 소유권을 유지한다. 이 부품은 실제 native runner에 아직 연결하지 않았으며 실행 권한을 주지 않는다. 외부 hook의 중단·join 협력이 필요하고 강제 종료나 자원 정리를 스스로 증명할 수 없다.
- 원본 native shadow는 실제 Jetson ARM/ROS Iron에서 원본 CDR·정수 시각·GID·RAW receipt를 보존하는 **유한 관측 probe**다. 지속 서비스로 사용하려면 단일 owner, 유한 큐, 명시적 Start/Stop과 원본 발행자 재검사가 필요하다. 15초 probe 반복 실행을 운영 경로로 대체하지 않는다.

## 적용까지 남은 작업

1. 원본 native 센서의 지속 owner를 연결하고, 실제 발행자·ROS ABI·물리 시계·원본 수신 시각·중단 정리를 검증한다.
2. 실제 LiDAR/IMU 장착 회전과 레버암을 측정해 차체 속도 피드백을 검증한다. 휠 엔코더·PWM·시뮬레이션 truth를 위치 입력으로 사용하지 않는다.
3. 원본 scan의 차체 주변 장애물과 주행 공간을 확인하는 정지 경로를 연결한다. 오래된 입력·불확실한 위치·장애물·권한 상실 시 0으로 귀결되도록 검증한다.
4. 실차 수동 기록으로 직진 feedforward, 좌우 편향, 제자리 회전의 추가 저항, 진동과 미끄러짐을 확인한다. 검증되지 않은 PWM 프로필을 측정된 값으로 표시하지 않는다.
5. ESP bridge에 자동 제어용 단일 lease·순번·deadman·watchdog를 연결한다. 늦은 응답이나 재연결로 오래된 명령을 다시 보내지 않아야 한다.
6. 제한된 거리에서 수동 정지·통신 단절·장애물 정지와 실제 제동 거리/시간을 확인한다. HTTP STOP ACK는 물리 정지의 증거가 아니다.
7. 그 후 과수열 추종·끝 지점·벽·마지막 과수열·회전·새 환경 대응을 실차 검증한다. GPS 수신은 별도 기능이며 GPS heading이나 융합 정확도 검증을 대신하지 않는다.

실차 자동 출력과 보정값 변경은 아직 수행하지 않았다. 이 문서의 완료 범위는 소스 준비와 명시적으로 기록한 시험뿐이며, 실차 자율주행 완료를 뜻하지 않는다.
