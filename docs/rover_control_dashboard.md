# Rover Control Dashboard

ESP8266 manual control uses the authenticated Dashboard session and `/run/ubts-rover/control.sock`. See [ESP8266 control](esp_rover_control.md) for ownership, stop behavior, USB mapping, and low-bandwidth profiles.

Live camera, LiDAR, IMU and rosbag2 recording/archive controls remain on `/rover-control`. Preview scaling does not change ROS recording inputs.
