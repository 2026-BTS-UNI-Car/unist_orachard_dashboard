# 과수원 자율주행 날(2026-11-20) 진행 절차

- 대상: 10/10에 갔던 과수원. 열 하나씩, 열 시작에서 자율주행 버튼 한 번, 열 끝에서 정지. 유턴·다음 열 없음.
- 근거: `docs/steering/ORCHARD_1120_KO.md`(브랜치 `orchard-1120`). 10/10 기록 재생은 **잰 기록(10/10 수동 주행, 조향 전 차, 개방 루프)**,
  SIM 수치는 **자리값 기반 SIM 결과**다. 둘 다 이 차의 과수원 성능이 아니다. 금요일 run이 첫 과수원 실측이다.
- 차에 깔린 설정: `config_motor_orchard_20261120.json`(브레이크어웨이 34 %, 정지 거리 0.595 m, 정지 조향 3.76°/s, 조향 상태 나이 0.6 s,
  격자 표시 켬). 조정 값: 목표 0.5, 배율 0.93, 앞봄 2.5/4.0, `speed_window_s` 1.5, `align_timeout_s` 10.

## 1. 첫 열 전에 (약 20분)

1. 차: 배터리 충전 상태와 전압 적기. 바퀴·벨트·가변저항 연결 눈으로 보기. 비상 정지(STOP)가 화면과 손 둘 다 되는지 한 번 확인.
2. 조향 영점(F1): 평평한 곳에서 직진 명령 때 바퀴가 곧은지 본다. 11/19 복도에서 직진 명령이 왼쪽 +2~5°, 차는 오른쪽 3~10 cm였다.
   잴 수 있으면 영점 각도를 적는다(설정 바꾸기는 사용자 결정).
3. 네트워크: Jetson AP(10.77.0.1)에 붙고 대시보드 Rover Control이 열리는지, heartbeat가 끊기지 않는지 30초 본다.
   화면을 가리거나 잠그면 1 s 뒤 `operator_link_lost`로 선다(정상 동작).
4. 센서 기록: Rover Control › 자율주행 탭의 **'출발하면 모든 센서 녹화'가 켜져 있는지** 본다(기본 켬). run마다 모든 센서가 '자율주행' 표시로 녹화되고
   run이 끝나면 멈춘다(녹화를 못 켜면 출발하지 않는다). 손으로 따로 켜 둔 녹화가 있으면 그 녹화를 그대로 쓴다.
   실행기 틱 기록(`~/ubts-row-executor/log/`)도 run마다 남는다.
5. GNSS 상태: fix 종류(RTK FIXED / FLOAT / 단독)와 위성 수를 첫 열 전에 한 번 적는다. 좌표는 적지 않는다.
6. 열 고르기: 처음 두 열은 **나무가 비교적 촘촘하고 끝 너머 4 m 이상 비어 있는 열**. 끝 너머에 기둥·통·사람이 없는지 본다.
   10/10 재생에서 실행기가 본 열 끝은 지도상 마지막 나무보다 0.8~4.1 m 뒤였다(2절).

## 2. 열 시작에 차 놓기

- 열 안으로 0.5~1 m 들어가서 놓는다(앞범퍼가 첫 나무 줄 근처). 두 줄의 나무가 LiDAR에 보여야 통로를 잡는다.
- **방향: 열과 ±10° 안**(눈으로 열 끝을 보고 맞춤). **옆: 가운데에서 ±0.3 m 안.**
- 특히 **이미 치우친 쪽으로 코가 향하게 놓지 않는다**(예: 왼쪽으로 치우쳤는데 코도 왼쪽).
  SIM에서 그 출발(+0.35 m, +20°)은 정지 정렬(바퀴를 12°까지 돌림) 중 `steering_not_following`으로 끝났다(2/2).
  방향 ±20°만, 옆 ±0.5 m만, 또는 가운데 쪽으로 향한 출발은 열 끝까지 갔다(자리값 기반 SIM 결과).
- 정지 정렬은 최대 10 s 걸린다(바퀴가 서 있을 때 느림). 그동안 차는 서 있고 바퀴만 돈다. 정상이다.

## 3. 열마다 진행

1. 열 길이 L 재기: 차 앞범퍼에서 그 열 마지막 나무까지(줄자, 걸음, 지도 중 하나). **Start에 `row_len_m` = L + 2 m**를 넣는다.
   거리 상한(backstop)은 L + 2 − 2 = L, 곧 마지막 나무 근처에서 멈추게 한다(실행기 거리는 ±5~10 % 틀릴 수 있다).
   L을 모르면 비워도 된다(상한 120 m).
2. GNSS 모드(비교군): 처음 두 열은 `off`. 그 뒤 같은 조건의 열을 `off` 한 번, `log_only` 한 번씩 번갈아 한다
   (`log_only`는 명령에 닿지 않고 기록만). `geofence`는 잘 된 열이 몇 개 쌓인 뒤에만, `weak_constraint`는 쓰지 않는다(설정에 없음).
3. 목표 속도: **첫 두 열 0.4 m/s**, 문제가 없으면 0.5로 올린다(조정 화면 target speed). 나머지 조정 값은 그대로.
4. 자율주행 탭에서 열 길이·GPS 고르고 **준비**(run 만들기·Arm) → **자율 주행 시작**. 화면은 계속 켜 둔다(가리면 1 s 뒤 섬).
5. 지켜볼 것: 상태(running), 통로 이유(`tracked_full_*`가 정상, `tracked_one_side_*`는 한쪽만 보임), 횡오차·방향, 속도, 열 끝까지 남은 거리.
6. 사람은 차 옆 뒤쪽에서 따라 걷고, 한 사람은 STOP에 손을 둔다. **열 끝 3 m 전부터 STOP 준비.**

## 4. 멈췄을 때

| 보이는 것 | 뜻 | 할 일 |
|---|---|---|
| `row_end`로 끝 | 정상 | 정지 위치를 적는다: 앞범퍼 − 마지막 나무 거리(앞이면 −, 지나면 +) |
| 상태가 `stopping_row_end`(또는 `stopping_*`)인 채 차는 서 있고 5 s 넘게 안 끝남 | 차가 멈췄는데 실행기가 '멈춤'을 확인하지 못함(SIM 4 m 간격 열에서 10 run 중 4번) | STOP 누름. 구동은 이미 0이다. 시각과 열을 적는다 |
| `steering_not_following` (래치) | 바퀴가 명령을 3° 넘게 2 s 못 따라감. 출발 정렬 중이면 출발 각이 큰 것 | 확인(ack) → 차를 더 곧게(±5°) 다시 놓음 → Start → Arm → go. 주행 중이면 바퀴·벨트·가변저항 점검 |
| `corridor_not_acquired` | 6 s 안에 통로를 못 잡음 | 차를 열 안쪽으로 1 m 더 넣고 곧게 다시 놓음 |
| `corridor_lost` / `corridor_lost_repeat_limit` | 1 s 넘게 통로를 잃음 | 차 위치(빈 나무 구간인지)를 적고, 그 자리에서 곧게 맞춰 새 run |
| `obstacle_ahead` 가 열 중간에서 | 앞 0.35 m + 정지 거리 안에 무엇이 보임 | 실제 장애물인지 본다. 차가 한쪽 나무 줄에 붙어 있었으면(10/10 재생에서 사람이 1.35 m 치우쳤을 때 났음) 가운데로 놓고 새 run |
| `row_end`가 열 중간에서(이른 끝) | 빈 나무 구간을 열 끝으로 봄 | 남은 거리와 빈 구간 길이를 적는다. 그 지점 바로 뒤에서 새 run으로 나머지를 간다 |
| 마지막 나무를 지나도 안 섬 | 열 끝 늦음 | 끝 너머 2 m에서 STOP. 지난 거리를 적는다. 다음 열부터 `row_len_m`을 꼭 넣는다 |
| backstop 거리·시간으로 끝 | 열 끝 전에 거리 상한 | 남은 거리를 적는다(실행기 거리 오차). 열 끝이 아니다 |
| `stale_lidar` / `stale_imu` / `operator_link_lost` (일시정지) | 입력이 늦음 / 화면 끊김 | 원인 확인 뒤 같은 run에서 go(재출발은 서 있을 때만) |
| `drive_no_response_repeat` | 명령을 냈는데 차가 안 움직임(땅이 무르거나 듀티 부족) | 바퀴 빠짐 확인. 반복되면 그 열은 접고 적는다 |

- 래치는 확인(ack) 뒤 Start부터 다시 한다. 래치를 원격으로 풀거나 가드를 끄지 않는다.

## 5. 열마다 적을 것(종이 한 줄)

시각 · 열 번호와 방향 · L(입력값) · GNSS 모드 · 목표 속도 · 출발 놓기(옆 cm, 방향 °) · 끝난 이유 · 정지 위치(마지막 나무 기준 ±m) ·
중간 정지(이유, 위치) · 빈 나무 구간 위치(눈으로) · 땅 상태(풀, 진흙, 경사) · 배터리 전압(5열마다).

## 6. 권하는 설정(금요일)

| 값 | 권함 | 까닭 |
|---|---|---|
| target_speed | 첫 두 열 0.4, 그 뒤 0.5 | SIM은 0.5에서 열 끝 정지(자리값). 10/10 재생에서 열 끝을 늦게 봄 → 처음엔 느리게 |
| speed_scale | 0.93 그대로 | 타일에서 잰 값. 과수원 흙·풀에서는 다를 수 있다. run 지표의 속도 비를 적는다 |
| lookahead 2.5 / 4.0 | 그대로 | 복도에서 출발 넘침을 줄였다. 과수원 SIM 횡 RMSE 0.05~0.11 m(1.5/3.0은 0.04~0.06 m), 둘 다 기준 0.20 안 |
| speed_window_s 1.5 | 그대로 | 10/10 재생: LiDAR 속도/지도 속도 0.97~1.06(복도의 0.5배 같은 치우침 없음), 최댓값 입력은 1.02~1.16배 → 듀티를 약간 낮게만 함 |
| align_timeout_s 10 | 그대로 | 정지 조향 3.76°/s에서 끝-끝 정렬 9.1 s |
| row_len_m | L + 2 m | 열 끝을 늦게 볼 때의 상한 |
